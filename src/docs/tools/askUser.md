# askUser

Ask the user a question and wait for their reply. Use it when a required value is genuinely
missing or a choice is the user's to make — not to confirm things you can determine yourself.

Requires an interactive session; it fails when there is no terminal.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `question` | string | Yes | The question to ask |

Full details: `readReference("askUser.md")`.
